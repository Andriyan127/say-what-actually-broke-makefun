## The entry

One line of error copy that names the real failure — an update that bricked
the device — and owns up to exactly how little testing went into it:

```
This update bricked your device. We tested it on one phone, in the office, on Wi-Fi — and it worked.
```

100 characters. No vague "something went wrong", no blame shifted to the
user — just the brutal truth, with a pause before the punchline.
